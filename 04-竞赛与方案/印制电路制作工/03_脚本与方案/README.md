## 路径约定

- 脚本目录：`03_脚本与方案/`
- 仓库根：`印制电路制作工/`（脚本内用 `os.path.dirname` 解析，无硬编码 `D:\nanyun\印制电路制作工\`）
- 草稿目录：`03_脚本与方案/_generated/`（可删可重建）

## 推荐工作流

1. 改内容 → 直接编辑 `01`/`02` 权威 docx  
2. 需要对照历史生成逻辑 → 运行脚本输出到 `_generated/`，人工 diff  
3. 旧版非权威 docx → 见 `05_归档备份/cross-review-2026-07-16/`

## 模块T（平台测试）约定（2026-07-17）

- 技术文件：模块T = **理论知识平台测试**（约45分钟，权重30%），试题由竞赛平台下发。
- **样题卷（02）禁止出现模块T试题/样题展示**（单选/多选/判断/简答等题干均不得出现）。
- 样题卷中模块T仅可保留结构说明：名称、时长、分值、平台作答说明。
- `generate_sample_paper.py` 仍含旧“模块一：理论知识”题库逻辑，仅供历史对照；不得用于覆盖权威完整版。
