# 印制电路制作工竞赛样题

江西省“振兴杯”职业技能大赛“印制电路制作工”赛项的公开样题与配套材料域。描述样题套次、模块边界与成果物语言，不含具体命题内容或实现细节。

## Language

### 套次与定位

**样题套次**:
一套可独立发布的完整公开样题包，与技术工作文件中的竞赛模块结构对齐。套次之间按同一模式编制。
_Avoid_: 试卷批次, 题库版本（除非特指理论题库）

**平行公开样题**:
与基准套次同构、同难度、同模块权重与时长框架，仅更换任务场景与预设缺陷内容的样题套次。用于多套轮换发布，稳定考核结构。
_Avoid_: 进阶样题, 正式赛题, 训练包（当实际为平行公开样题时）

**基准套次**:
已定稿、作为平行套次对标对象的样题套次。当前为第一套（0721 口径）。
_Avoid_: 母卷, 模板卷（口语可说“以第一套为模板”，正式术语用基准套次）

**主题换皮（L2）**:
平行公开样题的默认换皮深度：锁死考核结构与任务骨架，更换每套产品主题、预设缺陷布置与题面叙事；不重组模块步骤，不增删模块级考核大类。
_Avoid_: 最小换皮, 深度换皮（除非明确改档）

### 竞赛模块

**模块A**:
理论测试；平台机考，样题正文通常仅作说明，不附完整理论试题。

**模块B**:
EDA 工程设计；基于半成品工程完成封装/原理图补全、布局布线与 Gerber 导出。

**模块C**:
CAM 审核与工艺文件编制；对含预设缺陷的 Gerber 做 DFM 识别并填写缺陷记录表与简版制程工艺卡。

**模块D**:
成品板质量检测与缺陷分析；对含预设缺陷的成品裸板做外观、尺寸与指定点电气检测并给出处置结论。默认与本套 B/C **叙事独立**（独立检测板），除非另行约定挂接同一产品。

### 套内材料关系

**弱同源（B–C）**:
同一套内，模块 B 与模块 C 共享产品家族/外形与工艺档叙事；C 使用独立的“客户投产版”Gerber（含故意植入缺陷），不要求等于选手完成模块 B 后的正确设计结果。
_Avoid_: 强同源（C 必须由本套 B 标准答案导出）, 完全脱钩（B 与 C 无产品关联）

**同外形换缺陷图（D1）**:
模块 D 在多套样题间锁死板外形、层数、测点编号体系与任务骨架（V/M/E），仅更换丝印版本标识、预设缺陷布置与裁判答案键；可保留 A/B 双版本防抄袭。
_Avoid_: 每套全新外形板, 三套共用同一缺陷实物

### 已定套次主题（B/C 弱同源产品故事）

**第一套（基准）**:
LoRa 物联网核心板叙事（已定稿）。

**第二套**:
BLE 传感器节点叙事（无线传感类；与第一套接口类型拉开差异）。

**第三套**:
CAN 工控节点叙事（TJA1051 + LM75B + `TB_5.08_2P`）；与第二套形成无线/有线对照；版式与换题范式同第二套定稿效果。

**第四套**:
PCB15 Wi‑Fi 多功能控制节点叙事（源工程 `模块B.eprj2`）；B-0 为选手自制无线模组 **WM1** 封装（题面脱敏，禁止写可搜库真实型号）；含 RS485/电机/继电器等补全块；与第二套 BLE 题面并存、互不覆盖。

**模块B硬件策略（H3+H1）**:
第二、三套复用与基准套次同构的 MCU/电源/复位/LED/按键骨架（默认 STM32G0 族）；主外设按主题更换——第二套为 BLE 模组 + 等价 I2C 传感器，第三套为 CAN 收发器 IC + 等价 IO/可选传感器；B-0 各套仍为 1 个须自建的连接器类封装，且不得与第一套同一器件名/同一脚位图简单复用。
_Avoid_: SoC 直出射频强制匹配网络作为得分前提, 四层/HDI/BGA 作为满分前提

### 交付

**全量镜像（P1）**:
第二、三套的完成定义：文件角色与基准套次 1:1（题面、评分、B 半成品、C 选手/裁判材料、D 记录表与设计源等），可独立作为一套公开样题使用。

**分阶段推进（P3）**:
执行节奏：先主题与缺陷规格 + 题面/表格骨架 → 再 B/C 工程与 Gerber → 再 D 设计源与打样数据；目标态仍为全量镜像。

**硬对等（E1）**:
平行套次之间的难度合同：B 任务步数与骨架同构；C 缺陷处数 12±1 且大类覆盖与基准套次相同；D 保持 8 必检类型池 + A/B 双版本及底面≥3；禁止升级层数/强制高速与专用 AOI 依赖。
_Avoid_: 仅评分栏位对等, 自由浮动难度

**评分材料（S1 内核 / S2 目录）**:
各样题套次目录内各有一份完整《评分标准（第N套·0721口径）》；其中评价/测量维度与分值与基准套次同构（不漂移），套次相关真值与采分键写入该套文件附录或附表。
_Avoid_: 三套各写一套互不相同的评分维度, 样题包完全不附评分

**套次分包 + 角色子目录**:
每套样题对应 `02_样题/第N套/`；套内按交付角色分子目录：`01_样题`、`02_评分标准`、`03_结果呈现_参考答案`、`04_需填写内容`、`05_U盘资料`，另加内部 `99_命题规格`。不强制再拆 `选手/`、`裁判/` 人名目录；以外发角色为准。
_Avoid_: 全套文件无分类平铺, 强制按人名双目录

**制作顺序（O1）**:
先将第二套按分阶段推进走通至全量镜像可公开，再复用同一流程制作第三套。阶段 1 以第二套规格与题面骨架齐套为完成定义；第三套在第二套稳定前仅需保留主题级锚点。

**规格驱动工程回填（M1）**:
文字样题、表格、评分维度、缺陷/采分规格与工程回填清单由本仓库优先交付；模块 B/C/D 的立创工程、含缺陷 Gerber 植入与实物打样由命题人按规格在 EDA/板厂完成后再放回对应套次目录。
_Avoid_: 在无 EDA 条件时宣称工程已齐套

**套次命名（N1，解耦）**:
目录用中文套次名（`02_样题/第N套/`）区分资产。选手可见 docx **文件名与正文不写套次**（与第一套平行，如「竞赛样题（完整版）.docx」）；**仅完整版封面标题**可写「竞赛样题（第N套）」。模块 D 选手题面版本丝印与第一套同构可用 `MOD-D-S-A/B`；生产/命题侧可用 S2/S3 编码防混板。B-0 器件名按套区分。选手材料版式以第一套 docx 为母版，禁止另起炉灶重排。

**技术工作文件不可改（硬约束）**:
已定稿技术工作文件（0721 口径等）在制作第二、三套样题过程中**严格不得修改**。多套样题仅作为 `02_样题/` 下命题资产存在；不得借样题换皮回写模块结构、分值、设备或命题方式到技术文件。
_Avoid_: 为多套样题去改技术文件正文或附录清单

### 残余默认（已接受）

**第三套 B-0**:

**C 工艺能力表**:

**模块A（各套）**:
样题正文仅作说明，不附完整理论试题。
