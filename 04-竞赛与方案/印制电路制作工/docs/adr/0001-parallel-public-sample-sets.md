# 第二、三套采用平行公开样题 + 主题换皮

在已定稿第一套与不可修改的技术工作文件约束下，第二、三套样题定位为与基准套次同构、同难度、同权重的平行公开样题（非递进训练包、非正式赛题池）。换皮深度为 L2：锁死模块结构与任务骨架，更换 B/C 产品主题（第二套 BLE 节点、第三套 CAN 节点）与 C/D 预设缺陷布置；B–C 弱同源、D 同外形换缺陷图（D1）并保留 A/B 双版本；难度硬对等（E1）；交付目标全量镜像（P1）、执行分阶段（P3）、先二后三（O1）；工程资产规格驱动由人工回填（M1）；目录扁平按套次、命名带套次中缀（N1）；评分维度同构写入各套评分文件。不改技术工作文件。

**Considered Options**
- 递进训练包 / 正式赛题草稿池：会改变公开样题预期难度或保密边界，否决。
- 最小换皮（仅改坐标）：防背题弱；深度换皮（重组步骤）：冲击技术文件口径，否决。
- B–C 强同源或完全脱钩：强同源串行成本高，脱钩叙事割裂；取弱同源。
- 每套新外形 D 板 / 共用同一缺陷实物：成本或防背题失败；取同外形换缺陷图。
- 仓库强制选手/裁判人名双目录：过重；取套次目录 + 交付角色子目录（样题/评分/参考答案/需填写/U盘资料）。

**Consequences**
- 技术文件保持 0721 框架且严格不可改；样题套数与主题只存在于 `02_样题/`。
- 未回填立创工程前不得宣称 P1 齐套；阶段 1 以规格与题面为完成定义。
- 第三套在第二套跑通前仅保留主题锚点，避免双线同时漂移。
- 残余默认已接受：第二套 B-0=`PinHeader_2x5`，第三套 B-0=`TB_5.08_2P`；C 工艺能力数值沿用第一套；模块 A 各套仅说明不附理论卷。
- 选手材料高度解耦：docx 以第一套为母版复制改内容；**仅封面标题**可写「竞赛样题（第N套）」；附件文件名与正文不写套次。
- 第二套定稿效果固化为范式（`02_样题/00_平行样题_版式与换题范式.md`）；第三套按同法交付 CAN 节点实质换题（TJA1051/`TB_5.08_2P`/LM75B）。
- 第四套独立新建（PCB15 + B-0=题面代号 WM1 自制无线模组封装，脱敏防搜库），**不覆盖**第二套 BLE 题面；源工程放在 `02_样题/第四套/05_U盘资料/模块B.eprj2`。
