## 第6页｜总体建设思路（五句）

坚持 **“产业场景牵引、嵌入式技术支撑、软硬件协同、虚实结合、资源同步交付”**：

## 第7页｜总体架构图（感知—通信—实时决策—执行—反馈）

- **感知层**：温湿度、气体、光照、料位/水位、安防等（ESP32 无线 + 有线传感）
- **通信层**：RS485/Modbus、Wi-Fi/BLE、边缘网关协议转换
- **实时决策层**：STM32 + RT-Thread 线程调度、阈值与回差、本地规则
- **执行层**：风机、卷帘、喷雾、补光、声光告警
- **反馈层**：本地触控看板 + 嵌入式智能综合实训云平台
- **讲者备注**：手指沿五环走一遍，为第11页沙盘演示铺垫

## 第9页｜技术主线四件套

| 技术 | 角色 | 课堂可验点 |
|------|------|------------|
| **ESP32** | 低成本、低功耗无线养殖感知节点 | Wi-Fi/BLE 上报、断线重连 |
| **STM32** | 实时控制、GPIO/ADC/PWM/中断/RS485 | 外设驱动、执行机构控制 |
| **RT-Thread** | 多任务：采集/通信/决策/执行线程 | 线程调度、驱动封装、任务同步 |
| **RS485/Modbus** | 工业通信与执行联动 | 从站地址、寄存器读写、联动命令 |

- **禁止主线**：OpenHarmony / ZigBee / 鸿蒙物联网（对外不讲）
- **演示物**：四件套一页图 + 对应开发包照片

## 第11页｜沙盘闭环演示页（重点页）

**标题建议**：综合实训沙盘——可看见的嵌入式环控闭环

**会议金句流程（逐格动画）：**

1. 鸡舍温度采集  
2. RS485/Modbus 传输  
3. RT-Thread 阈值与回差判断  
4. 风机 / 卷帘联动  
5. 状态反馈与告警  

**沙盘构成要点：**

- 生猪养殖区 + 蛋鸡养殖区 + 环境调控区 + 饲喂饮水区 + 边缘控制与可视化区  
- ≥4 个嵌入式采集/控制节点；边缘网关；≥10 英寸本地触控  
- 离线仍可本地安全控制，网络恢复后同步记录  

**讲者备注**：本页可停留 2–3 分钟；若有沙盘视频/动图优先播。  
**风险点**：流程顺序勿乱；回差概念可用“防频繁启停”一句话解释。

## 第12页｜生猪 + 蛋鸡案例

**生猪智能养殖环境监测与精准环控实训系统 ×1**

- 分层：感知 → 嵌入式边缘控制 → 执行联动 → 云端教学
- 任务：温湿度舒适区、氨气/CO₂ 越限通风、饮水料位异常、栏舍安全

**蛋鸡智能养殖状态监测与禽舍联动控制实训系统 ×1**

- 任务：光照补偿、通风联动、产蛋计数、巡检识别、缺料缺水提醒
- 可与沙盘联调同一闭环句

- **专业群价值**：双高场景、双案例对照、可扩展到更多畜禽任务

## 第16页｜差异化与质疑应答（“是否只是物联网改名”）

**标准应答结构（口述 60–90 秒）：**

1. **承认载体成熟**：采用成熟模块化、免跳线平台，利于部署维护与分组教学。  
2. **强调目标转向**：从“物联接入与云应用验证”转向“**嵌入式实时控制、工业通信联调、RTOS 任务组织、养殖环控闭环**”。  
3. **给出可核对证据（≥5）：**

| # | 差异 | 本轮（会议一修） |
|---|------|------------------|
| 1 | 定位 | 嵌入式综合实验室（畜禽养殖环境智能监测系统开发） |
| 2 | 编制 | 13 套 × 4 人角色协同 |
| 3 | 预算 | 69.7230 万（非 86 万） |
| 4 | 技术主线 | ESP32 + STM32 + RT-Thread + RS485/Modbus |
| 5 | 结构 | 综合实训沙盘 + 生猪/蛋鸡双案例 |
| 6 | 闭环 | 阈值/回差 → 风机/卷帘执行反馈 |
| 7 | 政策 | 教职成〔2026〕1 号五要素 |

4. **禁止**：贬低旧方案、承认“换皮/更名”、对外主叙事写 OpenHarmony/ZigBee/鸿蒙物联网。

**讲者备注**：若被追问“硬件是否同一箱体”，答“教学载体模块化可复用，但建设目标、参数、验收、案例、编制与预算均按嵌入式综合能力重建”。
