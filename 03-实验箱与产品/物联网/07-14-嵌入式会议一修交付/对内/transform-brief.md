# 转型策略摘要：物联网方案 → 嵌入式会议一修（答辩用）

> 对内文档。用于同一客户对照旧物联网最终方案时的差异说明与“是否改名”标准应答。  
> 基线：会议一修 — 嵌入式综合实验室（畜禽养殖环境智能监测系统开发）建设项目。

## 1. 一句话定位

本项目不是“物联网综合实训室改名”，而是以猪舍/鸡舍生产任务为载体，建设 **嵌入式实时控制、工业通信联调、RTOS 任务组织、养殖环控闭环** 的综合实训能力。

## 2. 相对旧物联网最终方案的实质差异（≥5，答辩可指认）

| # | 差异点 | 物联网最终（客户可能见过） | 本轮嵌入式（会议一修） |
|---|--------|----------------------------|------------------------|
| 1 | 项目定位 | 物联网综合实训室 / 鸿蒙物联网实验箱 | **嵌入式综合实验室（畜禽养殖环境智能监测系统开发）** |
| 2 | 编制逻辑 | 25 套（1 人/箱隐含） | **13 套 × 4 人协同角色**（接线调试 / 程序开发 / 通信平台 / 数据分析） |
| 3 | 预算 | 约 86 万 | **69.7230 万**（教学仪器 50.2230 + 行业应用软件 19.5000，拟 2027 预算） |
| 4 | 技术主线 | 鸿蒙 / 物联接入 / 上云 | **ESP32 + STM32 + RT-Thread + RS485/Modbus** |
| 5 | 结构增量 | 无综合沙盘；常有独立课程平台 + 装修 | **畜禽综合实训沙盘**；资源并入平台与同步交付 |
| 6 | 案例场景 | 微生物发酵 + 泛智慧养殖 | **生猪精准环控 + 蛋鸡联动**（双高专业群） |
| 7 | 闭环演示 | 采集—通信—平台 | **阈值/回差实时决策 → 风机/卷帘执行反馈** |
| 8 | 政策锚点 | 职教数字化等泛表述 | **教职成〔2026〕1 号五要素** + 产教融合真实场景 |

> 答辩优先讲清 **1–5**；沙盘闭环与政策可作强化证据。

## 3. “是否只是物联网改名”标准应答

**口径（可直接口述）：**

1. **承认载体成熟**：桌面实验载体采用成熟模块化、免跳线平台，利于快速部署、维护和分组教学。  
2. **强调目标转向**：建设目标从“物联接入与云应用验证”转向“**嵌入式实时控制、工业通信联调、RTOS 任务组织、养殖环控闭环**”。  
3. **给出可核对证据**：  
   - 编制：13 套 × 4 人角色协同，非 25 套一人一箱堆叠；  
   - 结构：新增畜禽综合实训沙盘与双案例（生猪 + 蛋鸡）；  
   - 技术：ESP32 感知、STM32 控制、RT-Thread 多任务、RS485/Modbus 工业总线写入参数与验收；  
   - 预算与品目：69.7230 万及仪器/软件拆分与物联网征集方案不同。  
4. **禁止**：贬低旧方案、承认“换皮/更名”、对外主叙事写 OpenHarmony / ZigBee / 鸿蒙物联网。

## 5. 建设思路五句（会议对齐）

坚持 **“产业场景牵引、嵌入式技术支撑、软硬件协同、虚实结合、资源同步交付”**：

1. 以猪舍精准环控、鸡舍温感联动、饲喂饮水状态、设备巡检和故障诊断定义实训项目；  
2. 配置 ESP32 无线感知、STM32 实时控制、RT-Thread 多任务、RS485/Modbus 工业通信；  
3. 边缘网关与教学云平台支撑虚实结合与班级任务闭环；  
4. 沙盘实体化展示传感—总线—决策—执行—反馈；  
5. 指导书、视频、源码、点位表、评分与验收表与硬件同步培训、试运行、验收。
